Champ de bataille 3D

Clic gauche sur une armée bleue pour la choisir (Maj pour en ajouter, touches 1 2 3). Clic droit sur le terrain pour l'y envoyer, sur une armée rouge pour marcher sur elle. Glisser pour se déplacer, molette pour zoomer, glisser avec le clic droit pour pivoter. Espace centre la vue, Échap désélectionne.
